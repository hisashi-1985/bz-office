# 01_basics（基本情報・共通ひな型）

このフォルダはワークスペースに属さない **共通情報** です。どのワークスペースで作業していても参照してよい唯一のフォルダです。

- `profile.md` : 河合寿士のプロフィール・提供サービス・強み。提案書や自己紹介文の素材。
- `workspaces.md` : ワークスペース一覧と公開可否。社名の扱いはここを正とする。
- `templates/contracts/` : 汎用契約書ひな型（NDA、業務委託、顧問契約 など）
- `templates/regulations/` : 社内規程ひな型（就業規則、経理規程、職務権限規程 など）
- `templates/ipo/` : IPO 準備ひな型（スケジュール、予実管理、内部統制、審査対応 など）

## ルール
- ひな型には **固有名詞・実数値・特定の会社の事情を書かない**。会社向けに使うときは、各ワークスペース配下へコピーしてから編集する。
- ひな型の改訂はファイル名の版数を上げ、冒頭に改訂日と改訂理由を残す。
- 法令改正の影響があるひな型には、冒頭に「準拠法令・最終確認日」を明記する。
