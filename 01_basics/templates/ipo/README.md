# IPO ひな型

ここには **特定の会社に依存しない** ひな型だけを置きます。

## 想定するひな型
- IPO スケジュール（N-3〜N 期）・タスク一覧
- 事業計画・予実管理フォーマット
- 内部統制（J-SOX）文書: 業務記述書・フローチャート・RCM
- 上場申請書類（Ⅰの部・Ⅱの部）の目次・記載例
- 審査質問対応表・主幹事ヒアリング対応表
- 内部監査計画・監査報告書
- 関連当事者取引・反社チェックの整理表

## ファイル命名
`<種別>_<名称>_vN.<拡張子>` 例: `nda_双方向_v1.docx`

## 使い方
1. 使うときは各ワークスペース配下の部門フォルダへコピーしてから編集する。
2. ひな型自体を改良したら版数を上げ、冒頭に改訂日・理由・準拠法令の最終確認日を書く。
