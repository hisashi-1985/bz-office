# 規程ひな型

ここには **特定の会社に依存しない** ひな型だけを置きます。

## 想定するひな型
- 定款・株主総会運営規程・取締役会規程
- 職務権限規程・組織規程・稟議規程
- 経理規程・資金管理規程・固定資産管理規程
- 就業規則・賃金規程・退職金規程・育児介護休業規程
- 情報セキュリティ規程・個人情報保護規程
- 内部通報規程・反社会的勢力対応規程・インサイダー取引防止規程
- 関連当事者取引管理規程・予算管理規程

## ファイル命名
`<種別>_<名称>_vN.<拡張子>` 例: `nda_双方向_v1.docx`

## 使い方
1. 使うときは各ワークスペース配下の部門フォルダへコピーしてから編集する。
2. ひな型自体を改良したら版数を上げ、冒頭に改訂日・理由・準拠法令の最終確認日を書く。
