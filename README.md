# 売上・入金管理（bz-office）

売上の **実績・予測・売上管理・入金管理** を一元化するWebアプリです。
マネーフォワード クラウド会計の「仕訳帳CSV」を取り込むだけで、請求・入金・売掛金残高が自動で整理されます。

## 機能

| 画面 | 内容 |
| --- | --- |
| ダッシュボード | 期累計売上・着地見込・予実差・売掛金残高・期日超過のKPI、月次グラフ（実績／予測／前期）、今後6ヶ月の入金予定、要対応リスト |
| 売上管理 | 取引先×月の売上マトリクス（税抜）、請求一覧（入金状況・期日・状態）、手入力、CSV出力 |
| 入金管理 | 売掛金の年齢表、入金一覧と自動消込結果、手動消込、期首売掛金の回収状況 |
| 予算 | 取引先・区分ごとの月別売上予算。前期実績や現在の予測 ×成長率でたたき台を自動作成し、手で調整 |
| 売上予測 | 取引先・案件ごとの月別予測（確度つき）、実績からの自動作成（前年同月／直近3ヶ月平均／直近月）、予実差・着地見込 |
| 予実比較 | 予算・予測・実績・着地見込の月次表とグラフ（月次／累計）、取引先別の予算達成率 |
| 取引先 | 支払サイト（入金実績から自動推定・手動変更可）、別名、表記ゆれの統合 |
| データ取込 | MF仕訳帳CSVの取込（プレビュー→確定、再取込しても重複なし）、JSONバックアップ／復元、期首月・税率設定 |

### 取込ルール（MF仕訳帳CSV）
- 貸方「売上高」→ 請求（売上）。複合仕訳は取引No単位でまとめ、税抜額は「税額」列から算出
- 貸方「売掛金」→ 入金
- 開始仕訳の「売掛金」→ 期首売掛金
- 取引先が空欄の行は摘要から推定（全角/半角・法人格の違いは吸収）
- 摘要の「No.47」「請求書番号：40」を請求書番号として読み取り

### 自動消込
① 請求書番号一致 → ② 残高と同額の請求 → ③ 古い請求から順に充当。
当データにない請求書番号を含む入金や、最初の請求より前の入金は「期首売掛金の回収」と判定します。
結果は入金管理画面で手動修正できます。

## 使い方

```bash
npm install
npm run dev      # 開発サーバ http://localhost:5173
npm run build    # dist/ に静的ファイルを出力（任意の静的ホスティングに配置可能）
npm test         # ユニットテスト
```

## データの保存について
データはブラウザの localStorage にのみ保存され、外部サーバには送信されません。
複数PC・複数人で共有する場合は「データ取込 → バックアップ」でJSONを受け渡してください。
実データのCSVはリポジトリにコミットしないでください（`.gitignore` で除外済み）。
