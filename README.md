# bz-office

河合寿士（bz-office）が Claude と行う業務の **作業ルート** です。
OneDrive で旧 PC・ミニ PC 間を同期し、Claude Code / Claude Desktop の両方から同じフォルダを開いて使います。

- 全体ルール: [`CLAUDE.md`](CLAUDE.md)
- PC 移行手順: [`00_migration/MIGRATION_GUIDE.md`](00_migration/MIGRATION_GUIDE.md)
- 移行チェックリスト: [`00_migration/CHECKLIST.md`](00_migration/CHECKLIST.md)
- 基本情報・共通ひな型: [`01_basics/`](01_basics/)
- 業務ワークスペース: [`02_work/`](02_work/)

> このリポジトリは public です。クライアントの実データ・正式名称は `_private/` と各部門フォルダに置き、`.gitignore` でコミット対象外にしています（OneDrive では同期されます）。
